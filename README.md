# VSL Stats Lab

Отдельная тестовая песочница для учёта статистики волейбольного матча. Приложение читает публичные справочники VSL только через GET. Матчи сохраняются локально и синхронизируются через изолированную таблицу `stats_lab_matches`; рабочие таблицы VSL не изменяются.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Открыть `http://localhost:5174`. Для реальных справочников создать `.env.local` по `.env.example`; в локальной рабочей копии этот файл уже настроен и исключён из Git. Без конфигурации доступен деморежим.

```bash
npm run test
npm run lint
npm run build
```

## Данные

- `leagues`, `seasons`, `season_teams`, `teams`, `team_memberships`, `players`, `matches` — только чтение.
- Локальная копия матча — IndexedDB `vsl-stats-lab-v1`.
- Серверная копия — только `stats_lab_matches`, доступ через RPC из `supabase/stats_lab_schema.sql`.
- JSON — полная переносимая копия одного матча.
- CSV — агрегаты игроков; плюсы/минусы либеро не превращаются в процент приёма.

Не редактируйте один матч одновременно на двух устройствах: сервер отклонит устаревшую ревизию. После завершения действия откройте или обновите матч на втором устройстве.

## Ограничения P0

Реализован быстрый учёт: эйсы, очковые атаки, блоки, ошибки, ассисты к конкретной атаке и оценки либеро `+ / −`. Подробный режим всех попыток атаки и приёма 0–3 относится к P1.
